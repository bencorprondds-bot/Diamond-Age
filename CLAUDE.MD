# Diamond-Age

## Project Overview

**The Illustrated Primer** - An adaptive, AI-powered learning application inspired by Neal Stephenson's "The Diamond Age". This project creates a personalized educational companion for children that combines interactive storytelling, beautiful AI-generated illustrations, and gamified learning experiences.

### Vision
Build a modern version of Nell's Illustrated Primer - an intelligent tutor that adapts to each child's learning style, teaches through immersive narratives, and grows with them as they develop new skills.

## Project Goals

### Primary Users
1. **Son (Pre-Reader, Ages 4-6)**
   - Visual/audio learning interface
   - Gamified reading instruction (dungeon crawler style)
   - Word recognition through gameplay
   - "Read this word to beat that monster" mechanics

2. **Daughter (Elementary/Middle School, Ages 8-12)**
   - Interactive typing practice
   - Co-creative storytelling with AI
   - AI-generated story illustrations
   - Math, science, and art tutorials
   - Portfolio system for sharing creations

### Core Objectives
- Create adaptive learning experiences personalized to each child
- Build beautiful, engaging interfaces that inspire wonder
- Integrate AI for story generation and illustration
- Gamify learning without compromising educational value
- Foster creativity and critical thinking
- Provide safe, private, ad-free environment

## Notes for AI Assistants

### Important Context
- **Project Owner has no coding experience** - Explain technical concepts clearly and educationally
- This is a deeply personal project for the owner's children
- Prioritize child safety, privacy, and age-appropriate content
- Balance ambitious vision with incremental, achievable milestones
- Focus on building a solid foundation before adding complex features

### Development Approach
- This project is in early stages of development
- Follow the git branching strategy outlined above
- Always push to feature branches, never directly to main
- Use descriptive commit messages that explain the "why" not just the "what"
- Document decisions and explain technical choices
- Create working prototypes to demonstrate concepts
- Test thoroughly, especially for child safety features

### Priorities
1. **Phase 0:** Documentation and planning (current phase)
2. **Phase 1:** Basic UI and story generation proof-of-concept
3. **Phase 2:** User profiles and adaptive learning
4. **Phase 3:** Gamification for pre-reader
5. **Phase 4:** Advanced features (typing, art tutorials, etc.)

See ROADMAP.md for detailed implementation plan.
